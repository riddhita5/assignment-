# Firebase Authentication – Uses in Apps

* **Zomato:** Users can sign up/login using email, phone number, or Google account for quick and easy access.
* **Flipkart:** Firebase Authentication can provide secure login and OTP-based phone verification for users.
* **Spotify:** Users can use social login such as Google or Apple to sign in quickly without creating a separate password.
